# Serena - Centro de Estética
Um website para um centro de estética onde os clientes podem consultar os serviços disponíveis, preços, horários e informações do espaço, podendo futuramente realizar marcações online[cite: 1].

## 3. Estrutura do Website
O menu de navegação do website é composto por: **Início | Sobre nós | Serviços | Marcações | Contactos | Registo**

* **Início:** Apresentação do centro, destaques e serviços.
* **Sobre nós:** História, equipa e espaço.
* **Serviços:** Lista de tratamentos, fotos, descrição e preços dos serviços.
* **Marcações:** Formulário para marcações.
* **Registo:** Sistema de registo e login para clientes.
* **Contactos:** Morada, horário, contactos e formulário.
